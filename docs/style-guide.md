# ChekkPoint Style Guide — "Paper & Topo"

Source of truth: `src/styles.css` (tokens + classes), `src/components/Header.tsx`, `src/components/ui/*`, `public/topo.svg` (generated by `scripts/gen-topo.mjs`, checked by `scripts/verify-topo.mjs`). Mood reference: `dashboard_concept_b` mockup (UTMB finisher dashboard). History: `todos/pending/TODO-009.md`.

---

## 1. Brand essence & vibe

ChekkPoint is a race/ultra-running tracker. The look is **warm paper, fine topographic contours, frosted glass, serif headlines**. Quiet, editorial, a little bougie — like a printed trail map, not a cockpit.

Inspiration: **starlink.com** minimalism (huge whitespace, few elements, calm) + **topography** design (contour lines as texture).

| Do | Don't |
|---|---|
| Lots of whitespace; one idea per card | Dense dashboards, edge-to-edge chrome |
| Serif (EB Garamond) for titles & big numbers | Bold/heavy display type (`font-weight: 800`) |
| Muted forest / sage / clay on warm paper | Neon, emerald-on-black, cyan/violet glows |
| Hairline borders, soft diffuse shadows | Heavy drop shadows, thick borders |
| Frosted glass cards over topo lines | Dark theme, HUD/radar/"telemetry" gimmicks, mono fonts |
| Tabular numerals for times/splits | Proportional digits in data columns |
| Thin forest underline for active nav | Filled nav pills, bright hover states |
| Short, plain copy | Sci-fi jargon, exclamation marks |

**NOT futuristic.** Legacy radar and telemetry classes have been removed from CSS.

## 3. Typography

Fonts (`--font-display`, `--font-sans`) are **self-hosted locally** via `@fontsource/eb-garamond` and `@fontsource/manrope`. No runtime calls to Google Fonts.

| Role | Family | Class |
|---|---|---|
| Display / titles / big numerals | EB Garamond (fallback Cormorant Garamond, Georgia) | `.font-display`, `.display-title`, `.page-title` |
| UI, body, data | Manrope | default on `body` |

| Element | Spec |
|---|---|
| Page title `.page-title` | display, `clamp(2.5rem, 6vw, 3.4rem)`, lh 1.05, weight 400, ink |
| Subtitle `.page-sub` | Manrope 1rem, `--ink-soft`, max-width 42rem |
| Card title | display `text-xl` (h2/h3), weight 400, tracking −0.01em |
| Big numeral (tiles) | display `text-5xl`, `leading-none`, weight 400 |
| Body | Manrope `text-sm`–`text-base`, ink |
| Meta | 0.8rem, ink-soft (`text-muted-foreground`) |
| Label `.page-label` | 0.7rem, weight 600, uppercase, tracking 0.14em, forest |
| Table header | 0.75rem uppercase, tracking 0.1em, forest, bold |
| Nav | Manrope 500/600, ink-soft → ink |
| Brand | display 1.6rem, tracking −0.01em |

Preloading: WOFF2 assets for EB Garamond and Manrope are preloaded via `<link rel="preload" as="font" type="font/woff2">` in `src/routes/__root.tsx`.

## 6. Topography background

`public/topo.svg` is loaded **only once** on `body::before` as a fixed, hardware-accelerated layer:
```css
body::before {
  content: "";
  position: fixed;
  inset: 0;
  z-index: -1;
  pointer-events: none;
  background: url("/topo.svg") center / cover no-repeat;
  opacity: 0.65;
  will-change: transform;
  contain: strict;
}
```
This avoids expensive repaints during scrolling, eliminates duplicate downloads, and isolates the backdrop layer.

Pipeline verification:
```bash
node scripts/gen-topo.mjs      # writes public/topo.svg
node scripts/verify-topo.mjs   # size, round joins, mask, curve smoothness/cusps, decimals
```

## 7. Text readability scrim

Contours sit behind loose (non-card) text. A feathered paper-coloured radial backdrop mutes them locally:

```css
main, .site-header { isolation: isolate; }

.text-scrim::before, .page-label::before, .page-title::before,
.page-sub::before, .nav-link::before, .brand-pill::before {
  content: ""; position: absolute; inset: -1.25rem -2.5rem;
  z-index: -1; pointer-events: none;
  background: radial-gradient(ellipse closest-side at center,
    rgb(244 241 234 / .9) 0%, rgb(244 241 234 / .75) 50%, rgb(244 241 234 / 0) 100%);
}
```

## 8. Components (solid-ui First)

All application UI is built from genuine `solid-ui` components located in `src/components/ui/`, adhering to Kobalte accessible primitives:

| Component | Source File | Kobalte Primitive | Variants / Notes |
|---|---|---|---|
| `<Button>` | `ui/button.tsx` | `@kobalte/core/button` | `default`, `destructive`, `outline`, `secondary`, `ghost`, `link`, `pill`, `telemetry`. Sizes: `default`, `sm`, `lg`, `icon`, `pill`. Supports polymorphic `as={Link}`. |
| `<Card>` | `ui/card.tsx` | Native polymorphic | `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, `CardFooter`, `CardAction`. Glass default styling built in. |
| `<Badge>` | `ui/badge.tsx` | `@kobalte/core/badge` | `default`, `secondary`, `destructive`, `outline`, `forest`, `sage`, `clay`, `sand`, `amber`, `purple`, `chip`. |
| `<Separator>` | `ui/separator.tsx` | `@kobalte/core/separator` | Horizontal or vertical hairline dividers. |
| `<TextField>` | `ui/text-field.tsx` | `@kobalte/core/text-field` | Suite with `TextField`, `TextFieldInput`, `TextFieldTextArea`, `TextFieldLabel`, `TextFieldErrorMessage`, `TextFieldDescription`. |
| `<Input>` | `ui/input.tsx` | Native polymorphic | Styled with theme tokens `border-input`, `bg-surface`, `focus-visible:ring-ring`. |
| `<Textarea>` | `ui/textarea.tsx` | Native polymorphic | Styled multiline text area matching input styling. |
| `<Select>` | `ui/select.tsx` | `@kobalte/core/select` | `Select`, `SelectTrigger`, `SelectValue`, `SelectContent`, `SelectItem`, `SelectLabel`, `SelectDescription`. |
| `<Table>` | `ui/table.tsx` | Native container | `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`, `TableCaption`. Built-in responsive scroll container and hover states. |
| `<Alert>` | `ui/alert.tsx` | `@kobalte/core/alert` | `Alert`, `AlertTitle`, `AlertDescription`. Variants: `default`, `destructive`, `warning` (clay), `info` (forest). |
| `<Progress>` | `ui/progress.tsx` | `@kobalte/core/progress` | `Progress`, `ProgressLabel`, `ProgressValueLabel`. Hairline `bg-muted` track, forest fill. Label parts render Kobalte's own elements, not solid-ui's `<Label>`, since there is no control to label. |
| `<NavigationMenu>` | `ui/navigation-menu.tsx` | `@kobalte/core/navigation-menu` | Accessible navigation suite for header menus and popovers. |

### Nav Link Design Rationale
Header navigation in `Header.tsx` preserves `.nav-link` with its sliding 1.5px forest underline transition (`::after`, `scaleX` 0→1) rather than stock button pills. This directly matches the starlink.com editorial design ethos established in ChekkPoint's foundations.

## 9. Motion & Accessibility

### Prefers Reduced Motion
All transitions, animations, and smooth scroll behaviors automatically collapse when `prefers-reduced-motion: reduce` is detected:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms;
    animation-iteration-count: 1;
    transition-duration: 0.01ms;
    scroll-behavior: auto;
  }
}
```

### Contrast & Focus Visibility
- AAA contrast on primary ink on paper (10:1).
- Accessible focus rings: `focus-visible:border-ring focus-visible:ring-ring/40 focus-visible:ring-[3px]`.
- All interactive elements use Kobalte keyboard navigation and WAI-ARIA roles.
